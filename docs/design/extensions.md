# Agent customization and extension execution
<!-- budget: 6144 bytes, hard -->

The second AI layer changes the user's available capabilities. Plugin Studio owns
natural-language creation, edits, feedback, publication and evaluated revisions.
Installed plugins owns immutable artifacts, active pointers and their Cordis effects.
Disabling Studio leaves already installed effects active and reachable.

Supported generated surfaces are themes, reference widgets, bounded pure JavaScript
utilities and on-demand assistant skills. A skill retains its `SKILL.md`; a utility
retains generated source, declared inputs and actual callable effects. This does
not offer arbitrary generated server code, kernel mutation or scheduled skills.

Published and installed copies retain unique lineage; administrator promotion makes
an independent global copy. Artifact and manifest hashes are checked against ledger
identity and active registration. Enabling/disabling invokes real mount/disposal;
historical versions are selected only after their retained bytes verify.

Evolution proposals preserve base/candidate identity, source/descriptor diff,
rationale, risks, expected effect and rollback plan. Paired evaluation uses identical
frozen cases and records actual outputs, durations and measured costs. Unknown
checks stay unknown. Human review covers qualitative visual changes. Bounded live
trials retain observations; exceeded limits restore a verified prior revision and
record the result. Repeated failed attempts require explicit human review.

The operational assistant may prepare an inactive extension proposal. It cannot
activate a trial or grant human approval. The UI exposes preview, diff, cases,
shadow results, review, trial observations and restoration. All context given to a
model remains reconstructible under the store contract.
