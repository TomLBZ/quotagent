# 09 可观测性、评测与审计

## 1. 观测面（谁需要看什么）

| 读者 | 视图 | 来源 |
|---|---|---|
| 承包商运营 | 本包状态、待批事项、异常 Flag、供应商响应时效 | 账本投影 `view=contractor` |
| 供应商商务 | 待报价包、澄清答复、交期冲突、中标/失标结果 | 账本投影 `view=supplier` |
| 人工门审批者 | 待批队列 + payload + 引用链 + 风险提示 | `ctx.approval` |
| 审计/合规 | 事件切片、Merkle 根、重建校验、留存报告 | `ctx.evidence` |
| 工程/评测 | 指标趋势、影子重放差异、提案历史、回滚记录 | `ctx.eval` + `evolve/*` |

**投影原则**：投影是**可重建**的派生数据；丢掉缓存不丢事实。任何投影缺陷都修投影器，
不改账本（P4）。

## 2. 指标（业务 + 系统）

| 指标 | 定义 | 采集点 | 用途 |
|---|---|---|---|
| 报价可比率 | 无需人工重算即进入比价的报价占比 | `quote/normalized` | 痛点 1.4 |
| 口径一致率 | 字段语义校验通过率 | `norm` | AC-NORM-001 |
| 澄清轮次 | 同包同版本平均往返次数 | `clarification/*` | 痛点 1.3 |
| 比价耗时 | 末份报价到排名产出的时长 | `compare/rank-computed` | 痛点 1.5 |
| 人工改写率 | 人工相对 agent 草案的编辑比例 | 审批事件 payload | 自进化门约束 |
| 异常检出率 / 误报率 | Flag 命中与人工确认比例 | `compare/flag-raised` + 人工结论 | 护栏调优 |
| 重建一致率 | `rebuild(inputs) == observed` 比例 | `ctx.evidence` | INV / P4 |
| 重放确定性 | 同输入两次重放结果一致 | `ctx.eval` | 自进化硬门 |
| 端到端时延/失败率 | 各步骤耗时与错误率 | `kernel/*` | `10` 预算 |

**基线规则**：P0 只采集与记录基线，**不设目标值**；目标值由人在 P1 开始前设定并写入
项目 patch（`docs/work/roadmap.md` 的 G1 门）。

## 3. 评测套件

### 3.1 场景集（P1 最少三组）

| 场景 | 内容 | 断言要点 |
|---|---|---|
| S1 材料采购 | 单一币种、含税、条目 50~200、3~5 家投标 | 归一化正确、排序稳定、异常低价被标 |
| S2 分包工程 | 多包、接口责任交叉、含偏差与除外责任 | 接口覆盖检查、偏差影响入 TCO |
| S3 设备采购 | 长交期、付款条款复杂、外币 | 交期与付款条款折算、汇率时点一致 |
| S4 恶意输入 | 注入文本、漏项、虚假产能、伪造批准 | 全部被拦且留痕（red-team） |

场景数据全部为**合成数据**，随仓库入库（`[假设]` 真实数据涉及商业机密，不入库）。

### 3.2 断言层次

1. **不变量**：INV-001..010（`04` §6），任何场景都必须通过。
2. **行为**：给定账本切片，重放得到相同的排序与 Flag（确定性）。
3. **质量**：与人工参考答案对比（排序一致率、Flag 命中率）——**阈值由人设定**。
4. **成本**：token 与墙钟时间不超预算（`10` §3）。

### 3.3 反例集（red-team，永不删除）

每个历史事故/被拦截的恶意样本都追加为反例，且**用例只增不减**（防止通过改测试提高通过率，
`07` §4）。新增反例 = 一次 `evolve/proposed` 事件。

## 4. 审计流程（对外可交付）

```
1  ctx.evidence.export(scope=package_id, period) → pack{events[], merkle_root, manifest}
2  对方或第三方 ctx.evidence.verify(pack)        → 校验哈希链与签名
3  ctx.evidence.rebuild(pack, step)               → 重建该步模型输入
4  对照 pack 中记录的 inputs[] 逐条比对            → 一致率报告
```

`[假设]` 实际招投标审计对"电子证据"的采信标准因司法辖区而异，本设计只保证
**技术上的可验证性**，不主张法律效力。

## 5. 告警

| 触发 | 级别 | 动作 |
|---|---|---|
| 哈希链断裂 / 验签失败 | P0 | 停止对外发送，升级到人 |
| 出站报文含私域字段 | P0 | 阻断发送 + 留痕 + 通知安全负责人 |
| 承诺报文缺批准 | P0 | 拒收 + 告警 |
| 版本失配（报价 vs 包） | P1 | 挂起该报价 + 通知双方商务 |
| 澄清广播不完整 | P1 | 拒收 + 通知发包方 |
| 影子重放不确定性 | P1 | 冻结自进化提案 |
| 指标越界（canary 期间） | P1 | 自动回滚 |
