# ADR-0018 留存与销毁的边界：账本行永不销毁，销毁只作用于派生副本

- 状态：accepted（2026-09-21T10:52:57Z）
- 依据：`docs/work/decisions.md` D-047；需求 `FR-EVIDENCE-004`；约束 `FR-LEDGER-001`、`AC-AUDIT-001`、`AC-AUDIT-004`、`NFR-COMPAT-003`
- 实现：`src/quotagent/services/retention.py`（判定器）+ `src/quotagent/qa/checks_retention.py`（机检，21 条）
- 范围：本 ADR 只定**边界与判定**；**执行侧**（删除派生副本、读侧封存、落 `evidence/retention-*`）见清单 T-253

## 1. 决定

1. **账本行永不销毁**：删/改任一行即哈希链校验失败并停发（整本账报废），且会摧毁区分
   「篡改」与「授权删除」的唯一手段。「到期」= **读侧封存 + 派生副本销毁 + 密钥销毁**。
2. **到期动作四选一**：`keep` / `archive` / `destroy`（仅派生副本）/ `refuse`；判定为纯函数，
   时钟由调用方注入（同 `approval.sweep(now=...)`），**不读墙钟**。
3. **销毁分两类**：可重建副本（投影缓存、临时件）可自动；**不可重建物**（附件原文、归档包唯一份、
   密钥）**必须过人工门**（`scope=retention.destroy`）；超时只 remind/escalate/abort，**超时即继续留存**。
   一句话：*机器可以自动减少留存面，不可以自动消除唯一副本。*
4. **可验证性降级要写明**：归档包保留时独立验证成立（`AC-AUDIT-004`，`audit-verify.py` 不接触原账本）；
   销毁派生副本后，可验证性由**内容级**降为**存在性与完整性级** —— 有代价的选择，不声称无损失。
5. **留痕不得复活被销毁数据**：`evidence/retention-*` 的事件 body 只出计数与哈希。
6. `sealed` 区段的行**永不**进入 destroy 候选；归档包**一次成型**（事后补写即自证篡改）。

## 2. 被否决的选项

- **「销毁 = 从账本删行」**：与 `FR-LEDGER-001`、`AC-AUDIT-001` 直接冲突，且删一条即整本报废 → 否决。
- **「到期自动销毁唯一副本」**：不可逆且无人工门 → 否决（默认值必须是**留存**）。
- **「不区分可重建与不可重建」**：会让"丢缓存"与"毁证据"承担同一风险等级 → 否决。
- **「依赖墙钟判定」**：门会随墙上时间自己漂（比门红更危险）→ 否决，改为注入时钟。

## 3. 后果

- 好处：不可变性不被动摇；破坏性动作默认留存；销毁可解释、可审计、可拒绝。
- 代价：**存储不随"到期"释放**（只释放派生副本与密钥）；可验证性分级；
  执行侧尚未实现（`AC-AUDIT-003` 因此**不标绿**）。

## 4. 机检（`tools/verify.sh retention`，21/21）

逐条计数与动作对账、**账本行被判 keep + refused**、`guard_destroy()` 抛 `LedgerRowNotDestroyable`、
坏配置建策略即拒、未知类型不判销毁、垃圾输入不崩、**不依赖墙钟**（`now=None` 即拒）、
两次 `render()` 字节一致、静态与动态零残留、有界夹取、人工门带 `scope/ref/status=pending` 且
`auto_approved == 0`、超时策略只能 remind/escalate/abort、私域字段（INV-008）只记个数、`verify_plan` 能定位篡改。
