[5] 父方本轮自己犯的两个错（都当场修掉，写在这里免得下次重犯）
① **我的 `AC-UI-002` 机检曾在一条路径上"空转假绿"**：写入器把结果写在 `<shared>/pipeline.json`，
  而我按 `<shared>/ui-shared/pipeline.json` 找 → 断言读到空串仍判过。子代理指出后改成
  **按写入器 stdout 报告的路径定位**，并加了一条"报告了路径却没写文件 → 红"。**假绿比红更危险。**
② **改 `webui-serve.py` 时多插了一个 `]`** → `IndentationError` → 服务起不来、公网 502。
   教训：改服务入口脚本后**先 `py_compile` 并通过了再重启**，并把"编译失败就停"写成 `|| { echo 停; exit 1; }`
   （本轮第一次没写，脚本照旧往下跑，把服务留在了坏状态）。
（待 T-260 实现轮次落地后追加：写入器与插件的哈希、门与端到端输出、线上 /api/pipeline 真回读。）
