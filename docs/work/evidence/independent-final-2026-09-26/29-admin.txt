Help me create a useful personal plugin for my workspace.
QUOTAGENT
Built and loaded: RFQ Draft Builder is now in your Plugin studio (personal, not published).
What it does: you paste raw scope notes, it renders a numbered, copy-ready RFQ in plain text — sections 1–8 covering Scope, Priced items, Delivery, Commercial, Documents to submit, Qualifying criteria, Conditions and Contact.
Inputs it takes:
• Project + location, RFQ reference (auto-suggests RFQ-YYYY-NNN), issue date, submission deadline
• Trade/package and scope description
• Priced items, one per line: item | specification | quantity | unit — rendered as a wrapped text table
• Delivery address, required on-site date, supply-only vs supply-and-install
• Currency, pricing basis (firm lump sum / unit rates / both), payment terms, validity period requested
• Documents requested, qualifying criteria, exclusions suppliers must declare, buyer contact
Standard conditions it always applies: prices held firm for the stated validity period, full quantity coverage required, deviations only via a separate qualifications sheet, and a line confirming the buyer isn't bound to accept the lowest or any quotation.
Guardrails: it flags missing or malformed entries as "notes for buyer review", leaves unknowns as "to be confirmed by the buyer", and never sends anything — the footer states it's a buyer-review draft. It doesn't hold supplier costs or internal data.
Next step: open Plugin studio, run it once with a real package (project name and scope are required), then check the priced-items table alignment and the review notes before you issue the RFQ through your normal process. Tell me if you'd like a reusable version covering the full quote-comparison workflow as well.
