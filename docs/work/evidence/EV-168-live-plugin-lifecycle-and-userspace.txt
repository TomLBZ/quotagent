四、空 HOME + 断网的一键运行（含**没做到的那一半**）
--------------------------------------------------------------------------------
本环境 `unshare -n` 被权限拒绝（实测 `unshare: unshare failed: Operation not permitted`），**做不到内核级断网**。
因此验收用的是**进程级等效**手段：`tools/netblock.c` 编译成 `LD_PRELOAD` 垫片（拦 libc 层的 `connect()` 到非回环
地址、`getaddrinfo()` 非本机名字），外加代理黑洞 env 与包管理器离线开关。**它只能拦 libc 层**：静态链接的二进制、
raw syscall 不受它管 —— 这一行写进 `netblock.c` 的头注释，也在门的 detail 里打出来。

原始行（`tools/verify.sh run-once` R14a-f）：

    [ok] R14a 空 HOME + 断网下 `./run up` 成功：rc=0 healthy=True page200=True 垫片=编译成功（/usr/bin/gcc）
    [ok] R14b 断网判据**非空转自证**：垫片真的拦住了一次对外 connect
         connect 到 1.1.1.1 返回 101；留痕=['connect 1.1.1.1:80']
    [ok] R14c **不写 HOME**：`./run up` 之后空 HOME 里 0 个文件   HOME=…/empty-home-48675 内容=[]
    [ok] R14d 断网运行的 up 期间**零次非回环连接尝试**（垫片留痕为空）  留痕=[]（0 条）
    [ok] R14e 断网运行的服务能停干净：`down` 退出码 0 + 端口**真释放**
    [ok] R14f 能重启，且第二次 up 幂等：restart rc=0 pid=156950 二次 up=already-up pid 不变=True status 一致=True

**没做到的部分（如实标注）**：
 1. 没有内核级断网（网络命名空间不可用）⇒ "物理上发不出字节"这句话**不能**据此声称；
    能声称的是"在 libc 层被拦且启动路径**零次**尝试、up 仍成功"。
 2. 垫片不覆盖绕过 libc 的调用（静态二进制 / raw syscall）；本仓启动路径（sh/python/node/curl）都走 libc，
    所以这一条对本仓的结论有效，但不能外推成"任何程序都断网"。
 3. 空 HOME 只证明"仓库外的用户目录不被写"（`HOME` 里 0 文件）；`/tmp`、`/workspace/config.yaml` 等
    仓库外路径**没有**做写入面证明（`./run` 的纪律是只写 `tmp/`，但本批没做全盘写入面快照）。

六、本批**没**验证的东西（防"看起来完整"）
--------------------------------------------------------------------------------
 1. 运行期装卸只验了 `userspace/**` 的插件（badge / 也手工跑过 con-a 与 hello 的隔离内核装载）。
    `domain/**` 与 `system/**` 的插件走**同一条** live 代码路径但**没有**逐个真跑（`system/**` 被层锁刻意拒绝，
    只验了拒绝路径）。

    （27 §6.3 第 3 条的另一半）—— 本批的取证对象 badge 不注册路由。
 3. 运行期装卸的**并发**（两个 load 同时打进来）与**长稳**（跑几小时/多轮 reload 后的内存水位）未验。
 4. 控制令牌**只在 env 与 0600 文件两条来源**上验过；轮换（跑到一半换令牌）未验。
 5. `./run config init` 生成的文件只被 `tools/config-apply.py` 的解析器与门解析过；**没有**用管理道 UI 的
    "干跑/提交"路径真跑一遍（那需要人工门 + 0600 待办件全链路）。
 6. 断网垫片只在本环境（Linux + glibc）上验过，没在别的 libc/平台上验。
 7. `docs/design/28` 契约文本里"健康检查 GET /healthz"与实现的 `<prefix>/api/health` 这处偏差**本批没改**
    （已登记在 `one-command-run.md` §2 的诚实标注里）。
