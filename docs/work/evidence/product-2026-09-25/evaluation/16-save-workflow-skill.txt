What it does when you run it against the selected RFQ — read-only:
1. Lists submitted offers (supplier, quote ID, status, timestamp); stops cleanly if there are none — never borrows quotes from another RFQ
2. Recomputes each line (qty × unit price) and the quote total, flagging exact discrepancies
3. Classifies delivery and VAT per quote as included / separate line / excluded / NOT STATED (unknowns never treated as included)
4. Tabulates lead time and flags any that misses your required delivery date
5. Records exclusions and warranty as written, flags gaps and substitutions
6. Produces one draft clarification question per supplier (labelled "draft – not sent")
7. Closes with a missing-data list split into RFQ-side vs supplier-side gaps
Guardrails built in: uses only the selected RFQ's own records, deterministic arithmetic only, no invented prices or terms, and it never sends messages or awards/approves anything — it reads and reports only.
