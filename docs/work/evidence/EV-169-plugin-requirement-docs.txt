3. 「依赖（实测 import）」只覆盖承载文件的**静态 import 目标**，不含运行期通过桥/服务键获得的依赖。
4. 逐插件文档的 FR 行集合与映射表一致，是**用脚本比对**出来的（EV-169 第二节），但这套比对**没有进 `plugin-requirements` 门**
   （本批不改门脚本的判据面，只更新了 F4 的一处变异锚点字符串）——所以它是「本批取证」，不是「常驻机检」。

6. 改名（6 份核心文档）只改了文件名与映射表里的 `req=` 指针；**没有**检查仓库外（例如别的 worktree、
   工作区面板缓存、`user-space/**` 兼容链接目标）里是否还有指向旧文件名的引用。
7. `plugin-lifecycle` 的 L6 只在「去掉注入变量」这一个环境上验过是绿的；注入变量那种环境下的红是
