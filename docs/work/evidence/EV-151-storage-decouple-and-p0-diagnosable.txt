2.1 改动（tools/verify.sh，p0-no-node 分支）
· 子进程输出**不再丢**：每条 AC 的 stdout/stderr 落 `tmp/p0-no-node.<mktemp>/` 下的
  `<AC>.attempt<N>.log`；**真红时把该 AC 的输出原样回显**（`cat`）并在错误信息里给出完整日志路径。
· **隔离重试**：单条 AC 首次红 → `sleep 1` → **只重跑这一条**（同命令同环境）；
  **连续两次红才算真红**（exit 1）。首红次绿 = **瞬时命中**：不判红（exit 0），但把第 1 次的原样
  输出回显出来并打印日志路径（判据仍是"连续两次红"）。
· 日志目录每次 `mktemp -d` 独立新建 ⇒ **不与别的门共享临时路径**（并发跑不会互相覆盖/误删）——
  这一条同时把"共享临时路径"从候选假设里降级：本门自己的临时面是隔离的。
· 空集合守卫原样保留（`count < 34` → exit 2，拒绝假绿）。

    #!/bin/sh
    # 临时"无关写入者"（模拟运行中服务 / 定时任务往事实区落派生副本与反馈回执）。
    # 用法：sh tmp/zz-probe/concurrent-writer.sh <持续秒数>   （cwd 必须是仓库根）
    end=$(( $(date +%s) + ${1:-8} ))
    i=0
    while [ "$(date +%s)" -lt "$end" ]; do
      i=$((i + 1))
      printf '{"probe":%s,"at":"%s"}\n' "$i" "$(date -u +%H:%M:%S)" \
        > "tmp/ui-shared/zz-t277-concurrent-$((i % 3)).json"
      sleep 0.3
    done
    rm -f tmp/ui-shared/zz-t277-concurrent-*.json
    echo "writer: $i 次写入 + 删除临时文件（白名单外）"
