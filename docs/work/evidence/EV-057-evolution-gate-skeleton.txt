--- 口径说明（P1 骨架的边界）---
· 提案记录：必填字段齐备、id = 内容哈希；指标来源只认白名单（**模型自评被拒**）、每个指标至少一条账本引用；
  `target` 落在 `kernel.*` 一律拒绝（INV-010 / H5）；同类提案连续失败 3 次 → host 强制转人工（不再自动重试）；
· 归属：`journal.owner(key)` 可查；提案**不得占用文件或人工 patch 的键**（cut-in 被拒）；回滚只撤自己拥有的键；
· 影子：`isolate("shadow:"+proposal_id)` 隔离 realm，且**账本被复制到新文件**（否则幂等去重把重放变成重复投递）；
· 门：五条 AND 逐条给理由（目标指标不退化 / INV 全绿 / 反例集全绿 / 预算不越界 / **人工介入率不上升**），
  由 host 的 gate runner 计算，**不由提案模块自评**；
· 晋升：**P1 不允许自动晋升** —— 无 `approval_ref` 被拒、门未通过即使带批准也被拒；
· 回滚：`dispose()` 回收全部 effect + journal 撤回，不依赖人工删文件；
· 落账纪律：宿主不写账本（H1），5 条 `evolve/*` 事件经 `tools/evolve-record.py` 由 **Python 侧** append（seq 1..5）；
· 留 P2：canary 真实多方路由、自动晋升/自动回滚阈值、HMR（`ADR-0014 §7` 与评审 C §7.2）。
