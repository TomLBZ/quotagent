· 演示前后 `host/modules/**/*.mjs` + `src/**/*.py` 哈希不变；业务两侧账本零新增；公网未提权 401

[5] 集成缺陷（门抓到的，已修）
宿主 `user-plugin-manager.mjs` 的 `sha256()` 返回**裸 hex**，而 Python 侧写入器算的是 `sha256:<hex>` ——
写入器把"自述摘要与正文不符"判为**拒绝**（`自述不可信`），于是 created 一开始**没落账本**。
**这是门在尽责**：跨语言比对必须比的是**同一个摘要**，不是同一个字面量 → 已改为**归一化后比对**
（两侧都接受可选的 `sha256:` 前缀）→ 复跑立即通过。登记 D-062。
