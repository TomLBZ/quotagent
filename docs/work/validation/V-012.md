# V-012 · 供应商侧最痛的是「读包 + 澄清 + 重复录入」

## 假设与判定

- **假设**（`functional-requirements.md` §1）：供应商侧最痛的是『读包 + 澄清 + 重复录入』
- **验证方式**：访谈 3 家供应商
- **判定标准**：≥ 2 家认同则成立
- **影响**：决定供应商侧功能排序
- **判定态**：`pass` / `fail` / `partial`（部分成立时写 `partial` 并在结论里注明范围）

## 需要谁

- 3 家供应商的商务/预算人员（各 20 分钟）

## 准备的材料（已备好，可直接用）

- `templates/interview-form.md`（V-012 用其 B 段：痛点排序）

## 怎么做（步骤）

1. 请对方对 5 个候选痛点**排序**（读包、澄清、重复录入、对不上口径、交期评估），并要求各举一个最近的真实例子。
2. 记录排序结果与例子原话。
3. 汇总：把『读包/澄清/重复录入』排进前 2 位的家数 ≥ 2 → 成立。
4. 存证据 `docs/work/evidence/EV-<编号>-V-012-<供应商代号>-<YYYYMMDD>.txt`。
