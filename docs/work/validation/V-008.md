# V-008 · 电子证据在审计中的采信标准

## 假设与判定

- **假设**（`functional-requirements.md` §1）：电子证据在审计中的采信标准
- **验证方式**：咨询 1 名审计/法务
- **判定标准**：明确采信要求则修订 `09` §4
- **影响**：决定证据包形态
- **判定态**：`pass` / `fail` / `partial`（部分成立时写 `partial` 并在结论里注明范围）

## 需要谁

- 外部审计或法务 1 人（30 分钟）

## 准备的材料（已备好，可直接用）

- `templates/v008-audit-consult.md`（含 5 个必问问题，含『哈希链能否作为完整性证据』）

## 怎么做（步骤）

1. 把 5 个问题发过去（可邮件），请对方用一句话回答每个问题。
2. 特别记录：是否要求**第三方时间戳/公证**、是否接受**哈希链 + 独立验证工具**、留存年限要求（与 V-010 联动）。
3. **不要**把回答整理成法律意见；原话照抄。
4. 存证据 `docs/work/evidence/EV-<编号>-V-008-<来源>-<YYYYMMDD>.txt`。
