# V-002 · 供应商愿意提交结构化报价（对称性假设）

## 假设与判定

- **假设**（`functional-requirements.md` §1）：供应商愿意提交结构化报价（对称性假设）
- **验证方式**：用 S1 场景模板做 3 次盲测，看供应商是否接受模板与字段
- **判定标准**：≥ 2/3 接受则成立
- **影响**：决定 P1 是否有意义（**最关键的一条**）
- **判定态**：`pass` / `fail` / `partial`（部分成立时写 `partial` 并在结论里注明范围）

## 需要谁

- 3 家真实供应商的商务/预算人员；每家 30–45 分钟，可远程

## 准备的材料（已备好，可直接用）

- `templates/v002-supplier-blind-test.md`（发给供应商的说明，含 6 个问题）
- `templates/v002-quote-form.csv`（结构化报价表单；由我们按 S1 场景裁剪成 20 行）
- `examples/V-002-example-filled.csv`（填好的样子，可给供应商看示例）

## 怎么做（步骤）

1. 先跑一次备料演练，确认材料自洽（本文档末尾的『备料自检』命令），再联系供应商。
2. 从 S1 场景生成一份 20 行清单的包（`tools/run.sh -m quotagent.qa suite s1` 之后按需裁剪，或直接用 `documents/work/validation/templates/v002-quote-form.csv` 的 20 行版本）。
3. 请供应商**只填表单**（不看我们的系统），观察三件事：是否愿意填、哪些字段看不懂/不想填、要用多久。
4. 盲测后问 6 个问题（说明里有），记录**原话**，不要替对方总结成『接受/不接受』。
5. 把 3 家的记录（表单副本 + 问答原话）存成 `docs/work/evidence/EV-<编号>-V-002-<供应商代号>-<YYYYMMDD>.txt`。
6. 按判定标准汇总：接受的家数 / 3 ≥ 2/3。
