# V-009 · 异常低价判定的合理阈值

<!-- budget: 16 KB。结论状态见 register.json；结论由人签，agent 只备料与登记 -->

## 假设与判定

- **假设**（`functional-requirements.md` §1）：异常低价判定的合理阈值
- **验证方式**：用历史中标数据做分布分析
- **判定标准**：形成分布结论则写入策略 patch
- **影响**：决定 guard 默认值
- **判定态**：`pass` / `fail` / `partial`（部分成立时写 `partial` 并在结论里注明范围）

## 需要谁

- 数据/商务 1 人（30 分钟，能导出历史中标价）

## 准备的材料（已备好，可直接用）

- `templates/v009-price-distribution.csv`
- 现有实现：`services/guard.py` 的默认阈值 = 同包中位价的 60%

## 怎么做（步骤）

1. 导出**同一包内**各家报价（或历史中标价）的分布，按包分组，每组 ≥ 3 家。
2. 对每包算：最低价 / 中位价 的比值，记录下来。
3. 看这些比值的分布（最小值/中位数/第 5 百分位）——它们告诉你『多低算异常』。
4. 把结论写成一句可执行的话，例如『比值 < 0.7 时 90% 的人工复核认为可疑』，然后决定是否把 `guard` 默认阈值从 0.6 调到该值（改阈值 = 改策略 patch，需人签）。
5. 存证据 `docs/work/evidence/EV-<编号>-V-009-<来源>-<YYYYMMDD>.txt`（含每包比值明细）。
